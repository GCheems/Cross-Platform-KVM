# 设计文档

## 概述

跨平台键鼠共享系统是一个客户端-服务器架构的应用程序，允许多台设备在局域网中共享鼠标、键盘和剪切板。每个设备同时运行客户端和服务器组件，形成对等网络。系统使用UDP进行设备发现，TCP进行可靠的输入事件传输，并通过TLS加密保护所有通信。

核心设计原则：
- **低延迟**：输入事件传输延迟应小于50毫秒
- **跨平台一致性**：在Windows和macOS上提供相同的功能和用户体验
- **安全性**：所有设备间通信必须加密
- **容错性**：优雅处理网络中断和设备断开

## 架构

系统采用分层架构，主要包含以下层次：

```

└─────────────────────────────────────────┘
                    ↓

```

### 技术栈选择

- **编程语言**：Rust
  - 原因：跨平台支持、内存安全、高性能、优秀的并发模型
- **UI框架**：Tauri
  - 原因：轻量级、跨平台、使用Web技术构建UI
- **网络库**：tokio + tokio-tungstenite
  - 原因：异步IO、高性能、成熟的生态系统
- **加密**：rustls + ring
  - 原因：纯Rust实现、安全、高性能

## 组件和接口

### 1. 设备发现服务 (Device Discovery Service)

负责在局域网中发现其他KVM实例。

```rust
pub trait DeviceDiscovery {
    /// 开始广播本设备的存在
    async fn start_broadcasting(&self) -> Result<()>;
    
    /// 停止广播
    async fn stop_broadcasting(&self) -> Result<()>;
    
    /// 扫描局域网中的其他设备
    async fn scan_devices(&self) -> Result<Vec<DeviceInfo>>;
    
    /// 订阅设备发现事件
    fn subscribe(&self) -> Receiver<DiscoveryEvent>;
}

pub struct DeviceInfo {
    pub id: String,
    pub name: String,
    pub ip_address: IpAddr,
    pub port: u16,
    pub os_type: OsType,
    pub public_key: Vec<u8>,
}

pub enum DiscoveryEvent {
    DeviceFound(DeviceInfo),
    DeviceLost(String), // device_id
}
```

**实现细节**：
- 使用UDP多播在端口5353上广播设备信息
- 每5秒发送一次心跳包
- 如果30秒内未收到心跳，标记设备为离线

### 2. 连接管理器 (Connection Manager)

管理与其他设备的TCP连接。

```rust
pub trait ConnectionManager {
    /// 连接到远程设备
    async fn connect(&self, device_id: &str) -> Result<Connection>;
    
    /// 断开连接
    async fn disconnect(&self, device_id: &str) -> Result<()>;
    
    /// 获取所有活动连接
    fn get_connections(&self) -> Vec<Connection>;
    
    /// 订阅连接事件
    fn subscribe(&self) -> Receiver<ConnectionEvent>;
}

pub struct Connection {
    pub device_id: String,
    pub stream: TlsStream<TcpStream>,
    pub state: ConnectionState,
}

pub enum ConnectionEvent {
    Connected(String),
    Disconnected(String),
    Error(String, Error),
}
```

**实现细节**：
- 使用TLS 1.3加密所有连接
- 首次连接时进行设备认证（基于公钥）
- 实现自动重连机制（指数退避）

### 3. 输入捕获服务 (Input Capture Service)

捕获本地鼠标和键盘事件。

```rust
pub trait InputCapture {
    /// 开始捕获输入
    async fn start_capture(&self) -> Result<()>;
    
    /// 停止捕获输入
    async fn stop_capture(&self) -> Result<()>;
    
    /// 订阅输入事件
    fn subscribe(&self) -> Receiver<InputEvent>;
}

pub enum InputEvent {
    MouseMove { x: i32, y: i32 },
    MouseButton { button: MouseButton, pressed: bool },
    MouseScroll { delta_x: i32, delta_y: i32 },
    KeyPress { key_code: u32, modifiers: Modifiers, pressed: bool },
}

pub struct Modifiers {
    pub shift: bool,
    pub ctrl: bool,
    pub alt: bool,
    pub meta: bool, // Command on macOS, Windows key on Windows
}
```

**平台实现**：
- **Windows**：使用低级键盘钩子 (SetWindowsHookEx) 和鼠标钩子
- **macOS**：使用CGEventTap API


- **Windows**：使用SendInput API

- 处理快捷键触发的切换

### 输入事件协议

设备间传输的输入事件使用二进制协议：

```
┌────────────────────────────────────────┐
│ Header (8 bytes)                       │
├────────────────────────────────────────┤
│ - Magic Number (2 bytes): 0x4B56      │
│ - Version (1 byte): 0x01              │
│ - Event Type (1 byte)                 │
│ - Payload Length (4 bytes)            │
├────────────────────────────────────────┤
│ Payload (variable length)              │
└────────────────────────────────────────┘
```

事件类型：
- 0x01: MouseMove
- 0x02: MouseButton
- 0x03: MouseScroll
- 0x04: KeyPress
- 0x05: ClipboardSync
- 0x06: SwitchRequest
- 0x07: Heartbeat


## 正确性属性

*属性是指在系统所有有效执行中都应该成立的特征或行为——本质上是关于系统应该做什么的形式化陈述。属性作为人类可读规范和机器可验证正确性保证之间的桥梁。*

### 设备发现和连接

**属性 1：设备发现完整性**
*对于任何*在局域网中运行的KVM实例，启动后的扫描应该能够发现该设备，并且设备信息应包含名称、IP地址和操作系统类型
**验证需求：1.1, 1.2**

**属性 2：设备超时移除**
*对于任何*已发现的设备，如果30秒内未收到心跳包，该设备应该从设备列表中移除
**验证需求：1.3**

**属性 3：设备列表刷新一致性**
*对于任何*设备列表状态，执行刷新操作后的设备列表应该反映当前局域网中所有在线设备的实际状态
**验证需求：1.4**

**属性 4：未授权连接拒绝**
*对于任何*未经授权的设备，其连接尝试应该被拒绝，并且不应该建立任何通信通道
**验证需求：1.5, 8.4**

### 鼠标和键盘控制

**属性 5：边缘切换触发**
*对于任何*屏幕边缘位置，当鼠标在该位置停留超过200毫秒且存在相邻设备时，应该触发设备切换
**验证需求：2.1, 2.2, 2.5**

**属性 6：鼠标位置映射连续性**
*对于任何*设备切换，鼠标在目标设备上的位置应该对应于源设备边缘的相对位置，保持视觉连续性
**验证需求：2.3**

**属性 7：布局配置决定切换方向**
*对于任何*配置的设备布局，鼠标越过边缘时的切换方向应该与配置中设备的相对位置一致
**验证需求：2.4**

**属性 8：键盘输入路由正确性**
*对于任何*设备切换后的键盘输入事件，该事件应该被路由到当前活动设备，而不是其他设备
**验证需求：3.1**

**属性 9：按键传输完整性**
*对于任何*按键事件（包括普通键、组合键、特殊键），传输到目标设备后应该生成相同的按键码和修饰键状态
**验证需求：3.2, 3.3, 3.4**

**属性 10：输入延迟监控**
*对于任何*键盘输入传输，如果延迟超过50毫秒，系统应该记录性能警告
**验证需求：3.5**

### 剪切板同步

**属性 11：剪切板变化捕获和同步**
*对于任何*剪切板内容变化，系统应该在500毫秒内捕获并同步到所有连接的设备
**验证需求：4.1, 4.2**

**属性 12：文本剪切板往返一致性**
*对于任何*文本内容，在设备A复制后同步到设备B，设备B的剪切板内容应该与设备A的原始内容完全一致（包括格式和编码）
**验证需求：4.3**

**属性 13：图像剪切板往返一致性**
*对于任何*图像内容，在设备A复制后同步到设备B，设备B的剪切板图像应该与设备A的原始图像在像素级别一致
**验证需求：4.4**

### 配置管理

**属性 14：设备位置配置更新**
*对于任何*设备图标的拖动操作，配置中该设备的相对位置应该更新为新的坐标
**验证需求：5.2**

**属性 15：配置持久化往返**

**属性 16：分辨率自适应映射**

**验证需求：5.4**

**属性 17：边缘切换配置生效**
*对于任何*被禁用的屏幕边缘，鼠标在该边缘停留不应该触发设备切换
**验证需求：5.5**

### 快捷键控制

**属性 18：快捷键切换立即性**
*对于任何*配置的快捷键，按下该快捷键应该立即切换到对应的设备并发送切换确认

*对于任何*与系统快捷键冲突的快捷键配置，系统应该拒绝该配置
**验证需求：6.2**

**属性 20：快捷键唯一性**
*对于任何*两个不同的设备，不应该被分配相同的快捷键
**验证需求：6.3**

**属性 21：快捷键禁用生效**
*对于任何*快捷键被禁用的状态，按下快捷键不应该触发设备切换
**验证需求：6.5**

### 状态指示

**属性 22：状态指示器同步更新**
*对于任何*设备切换事件，所有设备的状态指示器应该在200毫秒内更新为当前活动设备
**验证需求：7.1, 7.2**

**属性 23：切换通知触发**
*对于任何*设备切换事件，如果通知功能已启用，系统应该显示切换通知消息
**验证需求：7.5**

### 安全性

**属性 24：通信加密强制**

**验证需求：8.1**

**属性 27：网络中断控制权返回**
*对于任何*网络连接中断事件，系统应该自动将控制权返回到本地设备
**验证需求：9.1**

*对于任何*网络连接恢复事件，系统应该在10秒内重新建立与之前连接设备的连接

**属性 29：主机断开控制权转移**
*对于任何*当前主机设备的断开事件，控制权应该转移到本地设备

**属性 30：网络延迟警告**

**属性 31：错误日志记录**

## 错误处理

### 网络错误

1. **连接超时**
   - 场景：设备在建立连接时超时
   - 处理：重试3次（指数退避：1s, 2s, 4s），失败后标记设备为离线
   - 用户反馈：显示"无法连接到设备X"通知

2. **连接中断**
   - 场景：已建立的连接突然断开
   - 处理：立即返回本地控制，尝试自动重连
   - 用户反馈：显示"与设备X的连接已断开"通知

3. **网络延迟过高**
   - 场景：往返延迟超过100毫秒
   - 处理：记录警告，继续运行但降低性能预期
   - 用户反馈：在状态栏显示延迟警告图标

### 输入处理错误

1. **输入捕获失败**
   - 场景：无法获取输入钩子权限（Windows）或辅助功能权限（macOS）
   - 处理：显示权限请求对话框，引导用户授予权限
   - 用户反馈：显示详细的权限设置指南

2. **输入注入失败**
   - 场景：无法在目标设备上模拟输入
   - 处理：记录错误，尝试重新初始化输入注入服务
   - 用户反馈：显示"输入传输失败"通知

3. **按键映射错误**
   - 场景：源设备和目标设备的按键码不兼容
   - 处理：使用按键映射表进行转换，无法映射的按键记录警告
   - 用户反馈：在日志中记录未映射的按键

### 剪切板错误

1. **剪切板访问失败**
   - 场景：无法读取或写入剪切板
   - 处理：跳过本次同步，继续监控后续变化
   - 用户反馈：在日志中记录错误

2. **剪切板内容过大**
   - 场景：剪切板内容超过10MB
   - 处理：显示确认对话框，询问用户是否继续同步
   - 用户反馈：显示"剪切板内容较大（X MB），是否同步？"对话框

3. **不支持的剪切板格式**
   - 场景：剪切板包含系统特定的格式
   - 处理：尝试转换为通用格式，失败则跳过
   - 用户反馈：在日志中记录不支持的格式

### 配置错误

1. **配置文件损坏**
   - 场景：配置文件无法解析
   - 处理：使用默认配置，备份损坏的文件
   - 用户反馈：显示"配置文件已重置为默认值"通知

2. **无效的设备布局**
   - 场景：配置的设备位置重叠或超出范围
   - 处理：自动调整为有效布局
   - 用户反馈：显示"设备布局已自动调整"通知

## 测试策略

### 单元测试

单元测试用于验证特定示例、边缘情况和错误条件：

1. **输入事件序列化/反序列化**
   - 测试各种输入事件的编码和解码
   - 边缘情况：空事件、最大值、特殊字符

2. **设备发现协议**
   - 测试UDP广播和接收
   - 边缘情况：格式错误的广播包、重复设备ID

3. **TLS连接建立**
   - 测试证书验证和握手
   - 边缘情况：过期证书、自签名证书

4. **配置持久化**

5. **平台特定API调用**

### 基于属性的测试

基于属性的测试用于验证应该在所有输入上成立的通用属性。我们将使用**proptest**库（Rust的属性测试框架）。

**配置要求**：
- 每个属性测试应该运行至少**100次迭代**
- 每个测试必须用注释标记对应的设计文档属性

**测试覆盖**：

1. **设备发现属性**（属性1-4）
   - 生成器：随机设备信息、网络状态
   - 验证：发现完整性、超时行为、授权检查

2. **鼠标切换属性**（属性5-7）

   - 验证：边缘检测、位置映射、方向正确性

3. **键盘输入属性**（属性8-10）
   - 生成器：随机按键码、修饰键组合
   - 验证：路由正确性、传输完整性、延迟监控

4. **剪切板属性**（属性11-13）
   - 生成器：随机文本（包括Unicode）、随机图像
   - 验证：同步时间、往返一致性

5. **配置属性**（属性14-17）
   - 生成器：随机设备位置、分辨率、边缘配置
   - 验证：配置更新、持久化、映射正确性

6. **快捷键属性**（属性18-21）
   - 生成器：随机快捷键组合
   - 验证：切换行为、冲突检测、唯一性

7. **状态和通知属性**（属性22-23）
   - 生成器：随机切换事件序列
   - 验证：状态同步、通知触发

8. **安全属性**（属性24-26）
   - 生成器：随机设备对、授权状态
   - 验证：加密强制、密钥唯一性、授权撤销

9. **错误处理属性**（属性27-31）
   - 生成器：随机网络故障、延迟、错误类型
   - 验证：控制权转移、自动恢复、日志记录

10. **跨平台属性**（属性32）
    - 生成器：随机输入事件
    - 验证：Windows和macOS行为一致性

## 实现注意事项

### 平台特定考虑

**Windows**：
- 需要管理员权限安装低级钩子
- 使用`SetWindowsHookEx`捕获输入
- 使用`SendInput`注入输入
- 防火墙可能阻止UDP广播

**macOS**：
- 需要辅助功能权限
- 使用`CGEventTap`捕获输入
- 使用`CGEventPost`注入输入
- 沙盒限制可能影响网络发现

### 性能优化

1. **输入事件批处理**
   - 将短时间内的多个事件合并为一个网络包
   - 减少网络往返次数

2. **剪切板增量同步**
   - 使用内容哈希避免重复传输
   - 大文件使用分块传输

3. **连接池管理**
   - 保持与常用设备的持久连接
   - 使用心跳包检测连接状态

4. **异步IO**
   - 所有网络操作使用异步模型
   - 避免阻塞主线程

### 安全考虑

1. **证书管理**
   - 每个设备生成自签名证书
   - 首次连接时交换公钥并持久化

2. **授权机制**
   - 使用设备ID和公钥指纹进行身份验证
   - 支持授权列表的导入/导出

3. **数据加密**
   - 所有网络传输使用TLS 1.3
   - 剪切板敏感数据加密存储

4. **权限最小化**
   - 只请求必需的系统权限
   - 明确告知用户权限用途

### 用户体验

1. **首次使用引导**
   - 检测并请求必要的系统权限
   - 提供简单的设备配对流程
   - 显示交互式布局配置教程

2. **视觉反馈**
   - 设备切换时显示短暂的边缘高亮
   - 活动设备在所有设备上有明显标识
   - 连接状态实时更新

3. **错误恢复**
   - 自动处理常见错误，无需用户干预
   - 提供清晰的错误消息和解决建议
   - 支持一键重置配置

4. **可访问性**
   - 支持高对比度主题
   - 提供键盘导航
   - 屏幕阅读器兼容
